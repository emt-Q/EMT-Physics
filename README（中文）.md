# EMT Physics 物理探索网站

## 项目简介
EMT Physics 是一个面向物理初学者的交互式学习平台，致力于为更多学习者提供平等的物理教育机会。平台通过AI图像识别技术自动分析物理题目关键词，精准匹配对应的PhET交互式物理仿真实验；内置「艾萨克牛顿爵士」AI 学习助手，随时解答物理疑问，让抽象的物理概念变得直观可感。

## 核心功能
✨ **沉浸式物理美学界面**
- 毛玻璃质感导航栏，点击可平滑滚动至对应区块
- 品牌光谱渐变配色，模拟能量流动的视觉效果
- Canvas动态量子粒子背景，营造物理宇宙氛围
- 全页面弹簧阻尼过渡动画，还原真实物理运动质感

🧠 **AI 学习助手「艾萨克牛顿爵士」**
- 基于豆包大模型（火山方舟 OpenAI 兼容接口），浏览器直连、开箱即用
- 随时提问物理问题，牛顿人设的回答风格，附带快捷提问入口
- 无需注册，配置一次 API Key 即可长期使用（Key 仅保存在本地浏览器）

🔍 **AI 智能实验匹配**
- 基于Tesseract.js的中英文OCR文字识别，上传物理题目图片自动解析
- **图像预处理增强**：自动缩放 + 灰度化 + 对比度增强，显著提升识别准确率
- **物理相关性判定**：非物理图片会收到「请上传和物理有关的题目哦～」友好提示
- 内置关键词匹配引擎，支持 **12 类** PhET 仿真实验：
  - 力学：单摆、力与运动、抛体运动、万有引力、浮力、流体压强、引力与轨道
  - 电学：电路模拟器、电容实验室
  - 能量：能量滑板竞技场、能量形式与转化
  - 波动：绳上波动
- 一键跳转至PhET官方交互式仿真实验室，无需额外安装软件

⌨️ **动态交互体验**
- 首页使命宣言打字机效果，模拟信号传输的光标动画
- 探究者姓名个性化问候（本地记住上次姓名）
- 实验启动倒计时爆炸动画、能量脉冲按钮、原生Web Audio生成的启动音效
- 匹配成功后的随机物理主题激励语录
- OCR 结果一键复制 / 清空重来

📱 **全设备适配**
- 响应式布局，完美适配桌面端与移动端浏览器
- 移动端聊天窗口自动变为全屏底部抽屉

## 技术栈
- **纯静态实现**：标准项目结构，HTML / CSS / JavaScript 分文件组织，无需构建工具
- **OCR引擎**：Tesseract.js v5（CDN加载，支持中英文识别，含图像预处理管线）
- **AI 助手**：豆包大模型 / 火山方舟 Ark API（OpenAI 兼容，浏览器直连）
- **仿真实验**：PhET Interactive Simulations 开源物理仿真平台
- **音效生成**：Web Audio API 原生合成启动音效，无需外部音频文件
- **背景动画**：Canvas 2D 实现粒子物理运动效果

## 使用方法
1. 环境要求：现代浏览器（Chrome 90+、Edge 90+、Safari 15+），需保持网络连接（用于加载OCR引擎、AI助手与打开仿真实验页面）
2. 直接在浏览器中打开 `index.html` 文件即可使用，或部署到 GitHub Pages / 任意静态托管
3. 使用流程：
   1. 在输入框填写你的探究者姓名，点击「继续」获得个性化问候
   2. 点击上传区域，选择包含物理题目的本地图片（支持单摆、电路、力学、波动等题型）
   3. 等待OCR识别进度完成，识别结果将显示在右侧面板
   4. 匹配成功后将显示对应实验名称与激励语录，点击「开启物理实验」
   5. 体验3秒实验启动动画后，将自动在新标签页打开PhET仿真实验室
   6. 遇到不懂的概念，点击右下角「艾萨克牛顿爵士」随时提问

### 配置 AI 助手（可选，首次使用需配置一次）
1. 点击右下角「艾萨克牛顿爵士」→ 右上角 ⚙
2. 前往 [火山方舟控制台](https://console.volcengine.com/ark) 开通豆包大模型
3. 创建「推理接入点」，复制 API Key 与模型 ID 填入设置
4. 点击「保存并测试连接」，显示「连接成功」即可开始提问
> 安全提示：API Key 仅保存在你的浏览器本地，请使用受限权限的 Key 并妥善保管。

## 扩展说明
如需添加更多物理实验类型，可在 `js/config.js` 中修改 `EMT.PHYSICS_SIMS` 数组：
```javascript
EMT.PHYSICS_SIMS = [
    {
        name: '实验名称 / English Name',
        keywords: ['关键词1', '关键词2', 'english keyword'],
        url: 'PhET实验链接'
    },
    // 继续添加更多实验
];
```
如需调整"物理相关性"判定，可修改 `EMT.PHYSICS_KEYWORDS` 与 `EMT.PHYSICS_STRONG_KEYWORDS`。

## 注意事项
- OCR识别准确率与图片清晰度、文字对比度相关，建议使用文字清晰、无过多背景干扰的题目图片
- 实验页面跳转至PhET官方平台，需保持网络连接才能正常加载仿真内容
- 首次使用OCR功能时，浏览器会自动下载中英文识别语言包，可能需要几秒等待时间
- AI 助手需要网络连接与有效的方舟 API Key
